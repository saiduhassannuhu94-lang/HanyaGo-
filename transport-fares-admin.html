Verifying authorised access…

1. Find a street or landmark

Search OpenStreetMap, choose a real map result, then save it as an unpublished candidate. Check the pin/name before publishing. Some smaller roads may be missing from public map data.

2. City fare rule

Use an actual operator-published fare or a locally verified tariff. A rate here estimates trips using the road distance. It is not an official government tariff unless the cited source proves that.

3. Exact route fare (overrides distance estimate)

Use this for a known fare between two precise locations. Both locations must be published, and the fare must be active and approved before passengers see it.
